# 📊 Dashboard de Satisfação dos Clientes

Projeto desenvolvido para o Projeto Integrador II do curso de Análise e Desenvolvimento de Sistemas.

O objetivo do projeto é analisar a satisfação dos clientes de uma transportadora através de respostas coletadas em formulário, utilizando Python para tratamento de dados e Looker Studio para visualização interativa.

---

# 🚚 Objetivo

Realizar uma análise da satisfação dos clientes em relação aos serviços de entrega da transportadora, identificando:

- Média das avaliações
- Principais problemas relatados
- Sentimento dos comentários
- Distribuição das respostas por cidade

---

# 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Google Forms
- Looker Studio
- GitHub

---

# 📈 Funcionalidades

- Leitura automática das respostas do formulário
- Classificação de comentários por sentimento
- Análise de problemas relatados
- Dashboard interativo com filtros por cidade
- Atualização automática dos dados
